# Jungeun — 자기소개 페이지

HTML·CSS로 만든 정적 자기소개 페이지입니다. AWS와 웹 개발을 배우는 과정, AI Exam Coach 프로젝트 및 Agent Forge 수상 경험을 소개합니다. 실행 파일은 [intro.html](./intro.html)이며 별도 서버 API나 빌드 단계는 없습니다.

## 실행

`intro.html`을 브라우저에서 직접 열거나 VS Code Live Server로 실행합니다. 로컬 서버를 쓰려면 저장소 루트에서 다음 명령을 실행하고 `http://localhost:8000/intro.html`을 엽니다.

```sh
python3 -m http.server 8000
```

Pretendard 글꼴은 외부 CDN을 사용하므로 같은 글꼴을 표시하려면 인터넷 연결이 필요합니다.
